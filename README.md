# CSQTT для Windows 10 x64

Клиент CSQTT на Wails v2, Svelte и TypeScript. Интерфейс и управление приложением работают в отдельной Go-оболочке. Rust-ядро и Go-помощник из v1.4.0 используются без изменений.

## Запуск

1. Скачайте ZIP из [Releases](https://github.com/but-rr/acad-csqtt/releases/latest), распакуйте целиком и запустите `CSQTT.exe`.
2. В «Настройках» укажите адрес сервера, пароль, хеши VK и, при необходимости, корпоративный HTTP-прокси с Basic-авторизацией.
3. На главном экране выберите системный прокси и/или TUN. Переключатель «Корпоративный прокси» выбирает HTTP CONNECT либо прямой интернет.
4. Нажмите круглую кнопку подключения. Во время подключения она позволяет отменить запуск; после подключения — отключиться. Доступность интернета подтверждается отдельно.

Корпоративный режим использует TCP CONNECT, внешний TURN-транспорт — TCP на 443. Прямого обхода при ошибке корпоративного прокси нет. Локальные SOCKS5/HTTP-прокси слушают только 127.0.0.1; стандартные порты — 1080 и 8080.

TUN запрашивает права администратора и использует подписанный Wintun из архива. IPv4 направляется через туннель, внешний IPv6 временно блокируется. Прежние системные настройки восстанавливаются при отключении и выходе. Более специфичные маршруты локальной сети сохраняются. Это не постоянный kill switch.

Сворачивание, крестик и Alt+F4 скрывают окно в трей. «Выход» в меню трея полностью завершает приложение и сетевые процессы. При аварии GUI помощник следит за процессом родителя; после принудительного завершения помощника восстановление выполняется при следующем запуске/подключении TUN.

Нужен Microsoft Edge WebView2 Runtime. На современных Windows 10 он обычно уже установлен; при его отсутствии загрузчик предложит установку. Python для запуска и сборки не требуется.

## DNS

В «Настройках» появился раздел DNS:

- **От сервера CSQTT** — значение по умолчанию, включая профили старых версий.
- **Google** — `8.8.8.8` и `8.8.4.4`.
- **Cloudflare** — `1.1.1.1` и `1.0.0.1`.
- **Свои DNS** — основной IPv4-адрес и необязательный резервный, без порта и схемы.

DNS используется локальными HTTP/SOCKS-прокси и назначается адаптеру CSQTT в режиме TUN. Настройка применяется при подключении; для её изменения сначала отключитесь. Значения сохраняются в переносимом `profile.json`. При отключении TUN его DNS и маршруты очищаются существующим механизмом восстановления.

Это DNS для трафика через установленный туннель. Первоначальное получение сессии VK/TURN и настройки DNS физических адаптеров Wi-Fi/Ethernet остаются прежними.

## Настройки и обновления

Поля автоматически сохраняются в `profile.json` рядом с EXE. Формат совместим с предыдущими версиями. Пароли и хеши хранятся открытым текстом. Закройте программу и перенесите всю папку на другой ПК — настройки сохранятся. Старые DPAPI-профили импортируются на исходном компьютере. При выключении сохранения сохранённые профили удаляются.

Проверка обновлений выполняется при запуске, раз в 6 часов и после подтверждения интернета. Новая версия показывается в модальном окне с размытым фоном. «Обновить» открывает страницу релиза GitHub; скачивание не начинается автоматически. «Позже» скрывает уведомление до следующего запуска. Проверить вручную можно в настройках.

Проверка использует выбранный корпоративный/прямой транспорт либо готовый локальный прокси. Для обновления закройте приложение и распакуйте новый ZIP поверх папки: профиль в публичный архив не включается.

Журнал ограничен 400 строками, обновляется пакетами и скрывает пароли и хеши. Его можно скопировать или экспортировать в TXT. Страницы сохраняют DOM при переключении; фоновые процессы, сеть и дисковые операции не выполняются в потоке WebView2.

## Сборка

Нужны Windows x64, Go 1.27.2+, Node.js 22.12+, Rust 1.97.1 и MSVC Build Tools. Версии приложения согласованы в `VERSION`, `wails.json` и `frontend/package*.json`.

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
go test ./internal/...
```

Структура:

- `frontend/` — Svelte/TypeScript, оформление и компоненты.
- `app.go`, `main.go` — Wails, жизненный цикл окна и API интерфейса.
- `internal/client/` — профиль, запуск процессов, журнал и проверки сети/обновлений.
- `internal/tray/` — трей и нативная видимость окна Windows.
- `core/rust-client/`, `packet-proxy/` — существующее ядро и сетевой помощник.
- `scripts/` — сборка и упаковка.

PR проверяется сборкой ZIP и коротким запуском EXE. Тег, совпадающий с VERSION, публикует архив и отдельный SHA256 в Releases. В корне архива — EXE, `bin` и `_internal`; полные тексты лицензий находятся в `_internal/THIRD_PARTY_NOTICES.txt`. Профили, ключи и настройки разработчика не публикуются.

При смене числа потоков учитываются согласованное значение TUNWORKERS и лимиты сервера. Ошибка 407 означает неверную Basic-авторизацию или неподдерживаемый способ авторизации; 403 — отказ CONNECT. Открытый порт 443 не гарантирует доступ к любому TURN-хосту. Данные CSQTT должны соответствовать серверу; хеши VK должны оставаться действительными.
