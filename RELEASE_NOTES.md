- Новый главный экран с круглой кнопкой подключения; параметры перенесены в настройки.
- Системный прокси Windows и TUN через Wintun с восстановлением сети при выходе.
- Прямое подключение без корпоративного прокси. Внешний транспорт — TCP / 443.
- TUN требует прав администратора; IPv6 на время подключения блокируется.
